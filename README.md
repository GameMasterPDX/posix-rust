# About the project

A implementation of the POSIX core utilities set, in Rust. Uses a library (`posix-lib`) for shared code and abstraction of std functionality.


# Implements

true
false
pwd

# Description of Crates.

posix-lib: The core library of this project.
true: The POSIX true utility.
false: The POSIX false utility.
pwd: the POSIX pwd utility.
